# HabitFlow Pro — Daily Habit Tracker & Analytics

> **A Mobile-First Habit Tracking & Personal Growth Application**  
> *Engineered by [Deepak Venkata Kumar Konijeti](https://github.com/deepakkonijeti5886-Ui-Design)*  
> Live Demo: [https://deepakkonijeti5886-ui-design.github.io/habitflow-pro/](https://deepakkonijeti5886-ui-design.github.io/habitflow-pro/)

---

## 📱 Features

- **Silky 60fps Habit Check-ins**: Tactile gesture-driven habit completions with celebratory particle animations.
- **30-Day Activity Heatmap**: Interactive GitHub-style streak visualization showing daily discipline trends.
- **Weekly Completion Rings**: Real-time radial velocity charts measuring weekly performance.
- **Motivational Insights & Streaks**: Dynamic progress calculations with motivational coaching cards.
- **Glassmorphism Dark UI**: Built with modern Tailwind CSS styling, ambient glows, and responsive mobile-first architecture.

---

## 🛠️ Tech Stack

- **Frontend**: Vanilla JavaScript (ES6+), HTML5, Tailwind CSS
- **Visualization**: Canvas Particle Engine, SVG Charts
- **State Management**: LocalStorage persistent offline data engine
- **Design Language**: Dark Mode Glassmorphism with micro-interactions

---

## 🚀 Quick Start

Simply clone the repository and open `index.html` directly in any web browser, or serve with any static web server:

```bash
git clone https://github.com/deepakkonijeti5886-Ui-Design/habitflow-pro.git
cd habitflow-pro
# Open directly in browser:
open index.html # On macOS
start index.html # On Windows
```
